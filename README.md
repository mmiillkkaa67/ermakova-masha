# Вариант 8. Комната отдыха

Курсовой проект по ПМ.02 «Разработка и сопровождение виртуальной системы сбора и учёта данных на Arduino».

## Входные данные
| Параметр | Значение |
|---|---|
| Сценарий | Комната отдыха |
| Датчик 1 (аналоговый), s1 | NTC — температура, 0–40 °C, вывод A0 |
| Датчик 2, s2 | LDR — освещённость, 0–100 %, вывод A1 |
| Датчик 3, s3 | PIR — присутствие, 0/1, вывод D2 |
| Исполнительное устройство | реле K1 (обогреватель), вывод D7 |
| LED / период T | зелёный, 15 мА (R1 = 200 Ом, вывод D8) / 5 с |
| Порог события | температура s1 < 20 °C |

## Файлы
| Файл | Назначение |
|---|---|
| `firmware/variant_08.ino` | скетч Arduino |
| `sim/diagram.json` | схема проекта Wokwi |
| `db/schema.sql` | создание таблиц readings и events |
| `db/queries.sql` | контрольные запросы |
| `db/load.sql`, `db/variant.db` | создаются автоматически (в Git не хранятся) |
| `nodered/flow.json` | поток Node-RED (импорт через меню ≡ → Import) |
| `nodered/parse_log.js` | код узла function «Разбор лога» |
| `data/log.txt` | журнал Serial Monitor (штатный сценарий) |
| `data/log_fault.txt` | тестовый журнал с неисправностью датчика s1 |
| `docs/` | схемы, перечень элементов, пояснительная записка |
| `start-nodered.bat`, `env.bat` | запуск Node-RED и командной строки с портативными программами |

## Порядок запуска
1. Запустить `start-nodered.bat`, открыть http://localhost:1880, импортировать `nodered/flow.json`, нажать Deploy.
2. Запустить симуляцию в Wokwi, скопировать вывод Serial Monitor в `data/log.txt`, сохранить файл.
3. Проверить данные: `sqlite3 db\variant.db ".read db\queries.sql"`.
4. Проверка неисправности: скопировать содержимое `data/log_fault.txt` в `data/log.txt`, сохранить — в events появится FAULT «датчик s1 вне диапазона».
